What it does

Four systems working as one pipeline.

QLoRA fine-tuned LLM

Llama-3-8B / Qwen-2.5-7B, NF4 + double quantization, r=16, α=32 on q/k/v/o projections, merged to FP16 for vLLM.

CNN vision router

ResNet18 classifies attachments into UI_ERROR, HARDWARE_FAULT, SPAM_IMAGE and VALID_DOCUMENT with temperature-calibrated confidence.

Agentic hybrid RAG

ReAct-style agent calls CNN, dense + BM25 knowledge search (with reflection) and an SLA lookup tool.

Confidence router

C_total = w₁·C_text + w₂·C_vision + w₃·C_rag. Below the calibrated threshold, the ticket goes to GPT-4o, Claude or Groq.

Platform capabilities

Production concerns built in, not bolted on.

Calibrated confidence

CNN logits are temperature-scaled on validation data; text confidence is the mean token probability of the generated JSON.

Reflective agent

If retrieval relevance is low, the agent re-queries the knowledge base using the CNN's visual hint before deciding.

Cost & latency telemetry

Every response reports route, latency, tokens and USD cost; /metrics aggregates fallback rate and spend.

Threshold calibration

A sweep picks the cheapest threshold that keeps quality retention above your target.

Hardened API

Typed Pydantic schemas, attachment size and format checks, and file access restricted to the data directory.

Containerised

Multi-stage CUDA image plus Compose services for the API, ChromaDB and a vLLM worker.

cp .env.example .env

docker compose -f deployment/docker-compose.yml run --rm api python -m data_pipeline.build_vector_store
curl localhost:8080/health

Multi-stage build

A CUDA devel stage builds the virtualenv; the slim runtime copies it, runs as non-root and exposes a health check.

GPU scheduling

Compose reserves NVIDIA devices for vLLM and the API; the merged FP16 model is mounted read-only.

Config via environment

Provider, threshold and API keys come from .env; no secret is baked into an image.

FAQ

Is my Groq key safe?

It lives in your browser's localStorage and is sent only to api.groq.com. Use a key you can revoke, and remove it any time from the assistant settings.

Are the benchmark numbers real?

Only after you run the benchmark yourself. The simulator and live stream on this page are illustrations, and they are labelled as such.

Can I self-host the whole stack?

Yes. The repository includes the training scripts, API and Docker Compose files. Training needs a CUDA GPU.
